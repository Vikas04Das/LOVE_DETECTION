# LOVE_DETECTION  💖

## Description
LOVE_DETECTION is an engaging and fun project that utilizes a creative algorithm to "detect" compatibility or love percentages between two names. It’s an interactive project designed to add a touch of humor and excitement for users.

This project demonstrates the following skills:
- **Frontend Development**: Built with HTML, CSS, and JavaScript for an appealing UI.
- **Logic Implementation**: Implements a unique logic to calculate compatibility.
- **User Interaction**: Includes a responsive design for better user experience.

## Features
- Enter two names to calculate the love compatibility percentage.
- Displays playful and creative results with animations (if applicable).
- Fully responsive UI for desktop and mobile devices.
